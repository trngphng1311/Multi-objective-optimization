# Multi-Objective Logistics Network Optimization

A multi-objective **Mixed-Integer Linear Programming (MILP)** model for designing a logistics network from suppliers to warehouses to customers, with the option of using **third-party logistics (3PL)** providers at each leg. Built in Python with **PuLP** and the **CBC** solver.

## Problem

Decide:

- **Where to open warehouses** (out of 4 candidate locations, max 7 allowed)
- **How much to ship** on each leg of the network: supplier → warehouse → customer, or supplier → customer directly
- **Which fleet to use** at each leg: in-house distribution teams or 3PL companies

…while balancing three competing objectives.

## The three objectives

| | Objective | Direction | What it captures |
|---|---|---|---|
| **F1** | Total cost | Minimize | Fixed warehouse setup cost, vehicle purchase cost, and annual variable shipping cost across all four flows |
| **F2** | CO₂ emissions | Minimize | Warehouse energy emissions plus per-km transport emissions across all flows and 3PL choices |
| **F3** | Job opportunities | Maximize | Jobs generated by opening warehouses, in-house fleet operations, and 3PL contracts |

This is a classic cost–environment–society trade-off: the cheapest network is rarely the greenest, and neither maximizes employment.

## Network structure

The model handles 8 flow variables connecting:

- **5 suppliers** (`I`)
- **4 candidate warehouse locations** (`B`)
- **10 customers** (`J`)

with shipping handled by either internal teams (`R`, `T`, `S`) or 3PL companies (`O`, `E`). Free shipping kicks in once a customer's purchase exceeds a threshold (μ = 65).

## Repository structure

```
LOGDES_Sets.py              # Index sets: I, J, B, S, O, E, R, T
LOGDES_Parameters.py        # Reads VU_DATA.xlsx → demand, costs, emissions, jobs, distances
LOGDES_Variables.py         # PuLP decision variables (binary + continuous)
LOGDES_OBJECTIVEFUNCTION.py # F1, F2, F3 definitions
LOGDES_CONSTRAINTS.py       # Capacity, demand, flow-balance, big-M constraints
LOGDES_MAIN.py              # Builds and solves each objective
VU_DATA.xlsx                # Input data: demand, costs, environmental, jobs, distances
```

## How to run

### 1. Install dependencies

```bash
pip install pulp pandas openpyxl
```

PuLP ships with the CBC solver, so no extra solver installation is needed.

### 2. Update the data file path

Open `LOGDES_Parameters.py` and update line 7 to point to your local copy of `VU_DATA.xlsx`:

```python
file_path = 'VU_DATA.xlsx'  # or full path on your machine
```

### 3. Run

```bash
python LOGDES_MAIN.py
```

The script solves each of F1, F2, and F3 individually under the same constraint set, then prints the optimal objective values and the values of all decision variables.

## Input data sheets (`VU_DATA.xlsx`)

| Sheet | Contents |
|---|---|
| `Product data` | Customer demand, vehicle capacities, product prices, fixed warehouse costs |
| `Cost data` | Variable shipping costs across all four flows and fleet types |
| `Environmental data` | CO₂ emission factors per warehouse, vehicle, and 3PL |
| `Job oppotunities` | Jobs created per warehouse, vehicle, and 3PL contract |
| `Distance` | Distance matrices: supplier–warehouse, supplier–customer, warehouse–customer |

## Notes and possible extensions

- The current `LOGDES_MAIN.py` solves the three objectives **independently** (lexicographic style). A natural next step is implementing a true Pareto front — for example via the **weighted-sum method**, **ε-constraint method**, or **goal programming** — to surface the trade-offs between cost, emissions, and jobs.
- The model uses big-M (`M = 10000`) constraints to link warehouse-opening binaries to flow variables; tighter formulations could speed up solve time on larger instances.
